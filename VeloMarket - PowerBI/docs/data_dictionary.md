# Data dictionary – raw sources

All files live in `data/raw/`. They are synthetic (generated by `data/generator/generate_data.py`, fixed seed)
and intentionally contain data-quality issues that are fixed in Power Query.

| File | Grain | Rows | Known issues (handled in Power Query) |
|---|---|---|---|
| `sales/sales_YYYY_MM.csv` (45 files) | order line | ~122k | mixed-case SKUs and stray spaces, lines re-exported in the next month's file (duplicates), QA test orders, empty CustomerID for walk-in customers, legacy SKU missing in master data, prices in local currency |
| `products.xlsx` (sheet `Products`) | SKU | 110 | report-style export: title rows above the header, Category/Subcategory only on the first row of each group, trailing spaces in names |
| `customers.csv` | customer version | ~26k | history rows (same customer several times → keep latest `UpdatedAt`), 10 spellings of 3 countries, random city casing, missing gender / birth year |
| `stores.csv` | store / channel | 14 | – |
| `returns.csv` | returned order line | ~6.6k | – (value & keys come from the sales line) |
| `inventory_snapshots.csv` | month-end × store × SKU | ~61k | semi-additive measure |
| `fx_rates_nbp.csv` | month | 45 | Polish locale (`;` delimiter, decimal comma), wide layout |
| `budget.xlsx` (sheets `Budget 2024/2025/2026`, `Mapowanie kategorii`) | month × country × category | 3 × 18 rows | wide layout (months as columns), Polish labels, values in thousands PLN, total row and total column |
| `security_users.csv` | user × country | 7 | – |

## sales_YYYY_MM.csv

| Column | Type | Description |
|---|---|---|
| OrderID | text | `SO-YYYY-NNNNNN` |
| LineNo | int | line number within the order |
| OrderDate | date | |
| ShipDate | date | = OrderDate for stores, +1–4 days for online channels |
| StoreID | text | FK → stores.csv (`TEST-01` = QA test orders) |
| CustomerID | text | FK → customers.csv, empty = anonymous walk-in |
| SKU | text | FK → products.xlsx |
| Quantity | int | |
| UnitPrice | number | list price in local currency (before discount) |
| DiscountPct | number | 0–0.30 |
| Currency | text | PLN / CZK / EUR |

## stores.csv

`StoreID, StoreName, Channel (Store / E-commerce / Marketplace), City, Country, CountryCode, Currency, Region, OpenDate, SalesAreaM2`

Stores opened during the analysed period: Poznań (2023-06), Łódź (2024-04), Brno (2024-09). Relevant for like-for-like analysis.

## customers.csv

`CustomerID, Gender (M/F/empty), BirthYear, City, Country, Segment (Retail / Club Member / B2B), SignupDate, MarketingConsent (Y/N), UpdatedAt`

## returns.csv

`ReturnID, OrderID, LineNo, ReturnDate, ReturnQty, Reason`

## inventory_snapshots.csv

`SnapshotDate (month end), StoreID, SKU, StockQty`

## fx_rates_nbp.csv

`miesiac (YYYY-MM); kurs_EUR; kurs_CZK`: average monthly mid rate, PLN per 1 unit of currency.

## budget.xlsx

Sheet `Budget YYYY`: `Kraj, Kategoria, Sty … Gru, Suma` + total row `RAZEM`. Net sales budget in thousands PLN.
Sheet `Mapowanie kategorii`: `Kategoria PL → Category`.

## security_users.csv

`UserEmail, Country`, where `ALL` = access to all countries. Used by dynamic RLS.
